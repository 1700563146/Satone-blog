# 产品范围

> 状态：阶段 0 交付物初始版，依据[开发文档](../开发文档.md) §2、§4 整理。需求变化时同步更新本文。

## 定位

单一站长的个人博客：展示个人品牌、发布文章、提供舒适的中文阅读体验。首期内容维护者为站长一人，访客为阅读者。

## 角色与场景

- 访客：浏览首页、查看文章、按标签/分类筛选、搜索、访问关于页面。
- 站长：以 Markdown 写作，通过 Git 提交与部署流程发布文章。
- 维护者：配置站点、检查构建、备份与恢复内容。

## P0（MVP 必须完成）

- 首页与文章列表、文章详情页
- Markdown 渲染、代码高亮、目录
- 分类与标签
- 关于页面与基本导航
- 响应式布局
- SEO 基础：标题、描述、规范 URL、Open Graph、sitemap、robots
- 404 页面与基础错误处理
- 内容版本控制与部署流程
- 基础测试、格式检查、构建检查

## P1（首版稳定后）

后台文章管理、草稿/预览/发布状态、站内搜索、RSS、友链、深浅主题、图床上传、访问统计、评论系统。

## P2（按真实需求决定）

定时发布、全文搜索、文章系列与阅读进度、音乐播放器、AI 辅助、多语言、多作者与权限。

## 非目标（首期）

多用户与复杂权限、通用 CMS、自建图床、AI 聊天、复杂社区功能、实时分析平台。
